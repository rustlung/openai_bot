# Telegram AI Bot

Минималистичный Telegram-бот на Python с поддержкой OpenAI API.

## Возможности

- 💬 **Диалог с AI** — общение через OpenAI GPT модели
- 🎭 **Режимы** — разные персонажи/стили ответов (настраиваются в `prompts.json`)
- 🧠 **Память** — бот помнит контекст диалога (последние N пар сообщений)
- 💾 **Persistence** — история и статистика сохраняются между перезапусками
- 🖼 **Генерация изображений** — команда `/image`
- 🎬 **Генерация видео** — команда `/video`
- 💰 **Billing** — подсчёт расходов в USD и RUB с актуальным курсом

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Обязательные переменные:
- `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `OPENAI_API_KEY` — API ключ от [OpenAI](https://platform.openai.com/api-keys)

### 3. Запуск

```bash
python main.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и справка |
| `/help` | Полный список команд |
| `/mode` | Выбор режима общения |
| `/reset` | Очистка истории диалога |
| `/cost` | Показать статистику расходов |
| `/reset_cost` | Сбросить счётчик расходов |
| `/image <описание>` | Сгенерировать изображение |
| `/video <описание>` | Сгенерировать видео |

## Конфигурация

### Переменные окружения (.env)

#### Обязательные

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram бота |
| `OPENAI_API_KEY` | API ключ OpenAI |

#### Базовые

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `OPENAI_MODEL` | `gpt-4` | Модель для текста |
| `HISTORY_PAIRS_LIMIT` | `5` | Пар сообщений в памяти |
| `MEMORY_FILE_PATH` | `data/memory.json` | Путь к файлу памяти |

#### Billing (цены на текст)

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `PRICE_TEXT_INPUT_USD_PER_1M` | `2.50` | Цена входных токенов (USD/1M) |
| `PRICE_TEXT_OUTPUT_USD_PER_1M` | `10.00` | Цена выходных токенов (USD/1M) |

#### Курс валют

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `FX_API_URL` | `https://api.frankfurter.app/latest?from=USD&to=RUB` | API курса |
| `FX_CACHE_FILE_PATH` | `data/fx_cache.json` | Файл кеша курса |
| `FX_CACHE_TTL_SECONDS` | `21600` | TTL кеша (6 часов) |
| `USD_RUB_RATE` | `75.92` | Fallback курс |

#### Изображения

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `IMAGE_MODEL` | `gpt-image-1` | Модель генерации |
| `IMAGE_SIZE` | `1024x1024` | Размер изображения |
| `IMAGE_COST_USD_1024x1024` | `0.011` | Цена за 1024x1024 |
| `IMAGE_COST_USD_1024x1536` | `0.016` | Цена за 1024x1536 |
| `IMAGE_COST_USD_1536x1024` | `0.016` | Цена за 1536x1024 |

#### Видео

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `VIDEO_MODEL` | `sora` | Модель генерации |
| `VIDEO_SECONDS` | `5` | Длительность (сек) |
| `VIDEO_SIZE` | `1080x1920` | Размер видео |
| `VIDEO_COST_USD_PER_SECOND` | `0.20` | Цена за секунду |
| `VIDEO_POLL_INTERVAL_SECONDS` | `3` | Интервал проверки |
| `VIDEO_MAX_WAIT_SECONDS` | `180` | Макс. ожидание |

#### Прочее

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `SHOW_COST_EACH_REPLY` | `0` | Показывать стоимость в ответах |
| `DEBUG_KEEP_MEDIA` | `0` | Сохранять медиа в data/tmp/ |

## Примеры использования

### Команда /cost

```
💰 Статистика расходов

Всего потрачено:
  💵 0.001234 USD
  💴 0.11 ₽

Детализация:
  📝 Текст: 3 запросов
```

## Архитектура

### Модули

- **config.py** — загрузка и валидация конфигурации
- **bot/handlers.py** — роутеры aiogram, обработка команд
- **storage/memory_store.py** — персистентное хранилище диалогов и billing
- **services/openai_client.py** — взаимодействие с OpenAI API
- **services/fx_rate.py** — получение курса валют с кешированием
- **utils/file_utils.py** — безопасная работа с файлами

### Billing

Все функции генерации возвращают `(result, meta)`, где `meta` содержит:
- `type`: тип запроса (text/image/video)
- `cost_usd`: стоимость в долларах
- Специфичные поля (токены, размер, длительность)

Стоимость рассчитывается автоматически и накапливается по чатам.
