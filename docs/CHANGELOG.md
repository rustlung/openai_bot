# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [0.1.0] - 2026-01-25

### Добавлено

- Базовая структура проекта Telegram-бота
- Интеграция с OpenAI API для генерации текста
- Система режимов (system prompts) через `prompts.json`
- Персистентная память диалогов в JSON файле
- Ограничение памяти по количеству пар сообщений
- Команды бота: `/start`, `/mode`, `/reset`
- Inline-клавиатура для выбора режима
- Конфигурация через `.env` файл
- Валидация обязательных переменных окружения
- Заглушки для будущих расширений:
  - `generate_image()` — генерация изображений
  - `generate_video()` — генерация видео
  - `estimate_cost()` — расчёт стоимости
- Подготовка статистики для billing в `MemoryStore`

### Структура

```
bot/handlers.py      — обработчики команд aiogram
storage/memory_store.py — хранилище памяти
services/openai_client.py — клиент OpenAI
utils/file_utils.py  — утилиты файловой системы
config.py            — конфигурация
main.py              — точка входа
```
