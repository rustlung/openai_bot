# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [0.2.1] - 2026-02-04

### Исправлено

- Обновлён источник курса USD→RUB на `open.er-api.com` из‑за отсутствия RUB в Frankfurter
- Улучшен парсинг ответа FX API для поддержки разных форматов

## [0.2.0] - 2026-01-25

### Добавлено

- **Billing система**
  - Подсчёт стоимости для текста (по токенам input/output)
  - Подсчёт стоимости для изображений (фиксированная цена по размеру)
  - Подсчёт стоимости для видео (по секундам)
  - Конвертация USD → RUB с актуальным курсом
  - Команда `/cost` — показ статистики расходов
  - Команда `/reset_cost` — сброс счётчика
  - Опция `SHOW_COST_EACH_REPLY` — показ стоимости в каждом ответе

- **Курс валют**
  - Сервис `services/fx_rate.py` для получения курса USD/RUB
  - Интеграция с Frankfurter API (данные ECB, без ключа)
  - Кеширование курса в `data/fx_cache.json`
  - Настраиваемый TTL кеша (по умолчанию 6 часов)
  - Fallback на статический курс при недоступности API

- **Генерация изображений**
  - Команда `/image <prompt>` для генерации картинок
  - Поддержка моделей gpt-image-1, dall-e-3
  - Настраиваемый размер (1024x1024, 1024x1536, 1536x1024)
  - Отправка как фото в Telegram

- **Генерация видео**
  - Команда `/video <prompt>` для генерации видео
  - Интеграция с OpenAI Sora API
  - Polling статуса с настраиваемым интервалом
  - Настраиваемый timeout
  - Отправка как видео в Telegram

- **UX улучшения**
  - Команда `/help` — полный список команд
  - Улучшенные сообщения об ошибках
  - Индикаторы "печатает" и "загружает фото/видео"
  - Статус-сообщения при длительных операциях

### Изменено

- Расширен `config.py` — добавлены все настройки billing, FX, image, video
- Переработан `services/openai_client.py`:
  - Реализована `generate_image()` с возвратом bytes
  - Реализована `generate_video()` с polling
  - Добавлен расчёт стоимости в meta
- Расширен `storage/memory_store.py`:
  - Добавлена структура billing для каждого чата
  - Методы `get_billing()`, `update_billing()`, `clear_billing()`
  - Детализация по типам: text/image/video
- Обновлён `bot/handlers.py`:
  - Добавлены обработчики /help, /image, /video, /cost, /reset_cost
  - Интеграция billing во все генерации
- Добавлен `httpx` в зависимости для FX API и скачивания видео

### Структура

```
services/
  ├── openai_client.py  — generate_text, generate_image, generate_video
  └── fx_rate.py        — get_usd_to_rub (NEW)
```

## [0.1.0] - 2026-01-25

### Добавлено

- Базовая структура проекта Telegram-бота
- Интеграция с OpenAI API для генерации текста
- Система режимов (system prompts) через `prompts.json`
- Персистентная память диалогов в JSON файле
- Ограничение памяти по количеству пар сообщений
- Команды бота: `/start`, `/mode`, `/reset`
- Inline-клавиатура для выбора режима
- Конфигурация через `.env` файл
- Валидация обязательных переменных окружения
- Заглушки для будущих расширений

### Структура

```
bot/handlers.py      — обработчики команд aiogram
storage/memory_store.py — хранилище памяти
services/openai_client.py — клиент OpenAI
utils/file_utils.py  — утилиты файловой системы
config.py            — конфигурация
main.py              — точка входа
```
